# Wacom Tablet Integration

This is the result of my lab work, where I had to interlink a Wacom CINTIQ Pro tablet to an experiment computer running an experiment paradigm written in Matlab. This required the tablet driver and the Matlab interface to mutex the data buffer, to be written by the tablet driver and to be read by the Matlab interface which then guides the experiment procedure using custom-built routines written in Psychtoolbox in Matlab.
